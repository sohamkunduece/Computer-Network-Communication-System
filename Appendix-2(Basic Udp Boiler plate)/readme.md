Application- Setup a UDP communication system.

Objective:
1.To setup a server which can talk with multiple clients.
2.Create a boiler plate for multi-client server and client
3.Ensuring the same client boiler-plate can be used to create multiple when executed.

How to run:
1. Open cmd and run the "server.py"
2. open another cmd tab and run the "client.py"
3. For  another client, just open a new tab  of cmd an dagain run "client.py"

Additional Information:
1.Server only sends back data what client sent.
2.A person has to manually close server or it will keep running.
3.Client manual removal is not done yet.
4.The output is completedly bare-bone done intentionally to help understand the principle. Gui can be later be added.
5. Authntication and client is not done here.
